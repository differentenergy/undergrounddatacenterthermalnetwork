## 🚀 Quick Deploy to GitHub Pages

### Step 1: Upload the `index.html` file

1. Go to your repository: https://github.com/differentenergy/undergrounddatacenterthermalnetwork
2. Click "Add file" → "Upload files"
3. **Upload the `index.html` file** (provided separately)
4. Commit with message: "Add BroadCore thermal infrastructure website"

### Step 2: Enable GitHub Pages

1. Go to **Settings** in your repository
2. Navigate to **Pages** (in left sidebar)
3. Under **Source**, select:
   - Branch: `main`
   - Folder: `/ (root)`
4. Click **Save**

### Step 3: Wait 2-3 minutes

Your site will be live at:
**https://differentenergy.github.io/undergrounddatacenterthermalnetwork/**

## 🎯 What Is BroadCore?

**Transform data center waste heat into neighborhood warmth**

### The Problem
- Data centers generate 80°C waste heat 24/7
- Cooling costs $4M+/year for 50 MW facility
- Homes waste energy heating/cooling
- Both problems, same location

### The Solution  
- Underground BroadCore pipes (10m deep)
- Connect DCs to homes
- **Winter**: DC heat → home warmth
- **Summer**: DC cooling → home comfort

### The Impact
- **40%** cost reduction for data centers
- **$1,200/year** savings per home
- **25,000 tons** CO₂ reduction
- **4.2 years** payback period
